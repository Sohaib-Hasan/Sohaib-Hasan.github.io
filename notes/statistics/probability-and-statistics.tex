% ========================================

% A master document spans many \section topics, so the left header cannot be a

% the wrong topic for most of the book here). Instead it tracks the current
% \section automatically:

% Some section titles run long (e.g. "Units and Their Conversions, Dimensions,

% instead of competing with the title for the same line.
